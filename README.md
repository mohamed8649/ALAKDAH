# كلاسيك نوار — صفحة منتج بيعية

صفحة هبوط بيعية بالعربية (RTL) بـ HTML و CSS و JavaScript خالصة، بدون أي مكتبات أو أُطر.

## التوجّه التصميمي

التصميم مبني على **الأسلوب التحريري السويسري** المستعمل في كتالوجات الساعات المطبوعة،
وهو اختيار متعمّد للابتعاد عن مظهر قوالب SaaS الجاهزة. القواعد المتّبعة في كل الصفحة:

- **خلفية ورقية دافئة** (`#f2efe8`) وحبر أسود — لا خلفيات داكنة ولا تدرّجات.
- **لون واحد فقط** (`--oxblood`) يُستخدم بندرة: السعر، التوفير، أخطاء النموذج.
- **لا زوايا مستديرة، لا ظلال، لا توهّج، لا إيموجي.** الفصل بين العناصر بخطوط شعرية بعرض ١px.
- **شبكة غير متماثلة**: عمود رقم القسم ٧٠px ثم العنوان ثم الشرح.
- **الطباعة تقود التصميم**: عناوين بخط Amiri (نسخ) ونصوص بـ IBM Plex Sans Arabic.
- **لا بطاقات**: المميزات قائمة مرقّمة، والأسعار جدول، والمواصفات ورقة مواصفات.
- **حقول بخط سفلي فقط** بدل الصناديق المستديرة.

## التشغيل

```bash
python3 -m http.server 8000   # ثم افتح http://localhost:8000
```

## البنية


## التخصيص

| ما تريد تغييره | المكان |
|---|---|
| الألوان والخطوط والهوامش | `css/style.css` → `:root` |
| الأسعار | `js/main.js` → `PRICES` + جدول `.ladder` + `#qty` |
| مدة العرض | `js/main.js` → `SPAN` (٦ ساعات) |
| رقم الواتساب والهاتف | `index.html` → `.wa` و `.dock__wa` والفوتر |
| المدن | `index.html` → `<option>` داخل `#city` |
| صورة المنتج | استبدل `assets/images/watch-main.jpg` |

## ربط النموذج بخادم

الإرسال حالياً **محاكاة** داخل المتصفح ويُحفظ في `localStorage` — الطلبات لا تصل لأحد.
لربطه، استبدل كتلة `setTimeout` داخل معالج `submit` في `js/main.js`:

```js
fetch('/api/orders', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(order)
})
  .then(function (r) { if (!r.ok) throw new Error(); return r.json(); })
  .then(function (res) { /* أظهر النجاح ورقم الطلب res.id */ })
  .catch(function () { note('تعذّر الإرسال، حاول مجدداً'); });
```

> التحقق في المتصفح لتجربة المستخدم فقط — تحقّق من البيانات على الخادم أيضاً.

## ملاحظات تقنية

- الأرقام العربية في كل العدادات، ورقم الجوال يُقبل بالأرقام العربية أو اللاتينية
  بصيغ `05XXXXXXXX` و `5XXXXXXXX` و `+9665XXXXXXXX`.
- متجاوبة حتى ٣٢٠ بكسل بلا تمرير أفقي؛ جدول الأسعار يتحوّل إلى صفوف مستقلة على الجوال،
  وصورة المقدمة تمتد إلى حافتي الشاشة.
- تحترم `prefers-reduced-motion`.
- الأرقام والآراء في الصفحة نصوص نموذجية — استبدلها ببياناتك الحقيقية قبل النشر.
