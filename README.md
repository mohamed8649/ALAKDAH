# صفحة هبوط بيعية — الساعة الكلاسيكية السوداء

صفحة هبوط (Landing Page) بيعية بالعربية، مبنية بـ HTML و CSS و JavaScript خالصة بدون أي مكتبات خارجية.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## البنية

```
index.html            الصفحة الكاملة
css/style.css         التنسيقات (متغيرات CSS + تصميم متجاوب)
js/main.js            العداد، العروض، التحقق من النموذج، الأسئلة الشائعة
assets/images/        صورة المنتج
```

## أقسام الصفحة

شريط عروض متحرك · هيدر ثابت · قسم رئيسي مع عداد تنازلي ومؤشر كمية · شريط ثقة ·
المميزات · المواصفات · آراء العملاء · باقات الأسعار · نموذج الطلب · الأسئلة الشائعة ·
دعوة أخيرة · فوتر · شريط طلب سفلي للجوال · زر واتساب.

## التخصيص

| ما تريد تغييره | المكان |
|---|---|
| الأسعار | `js/main.js` → `PRICES` و بطاقات `.offer` و `#qty` في `index.html` |
| مدة العرض | `js/main.js` → `WINDOW_MS` (٦ ساعات افتراضياً) |
| الألوان | `css/style.css` → المتغيرات في `:root` (`--gold`, `--bg`, …) |
| رقم الواتساب والهاتف | `index.html` → الرابط `.wa` و الفوتر |
| المدن | `index.html` → عناصر `<option>` داخل `#city` |
| صورة المنتج | استبدل `assets/images/watch-main.jpg` |

## ربط النموذج بخادم حقيقي

الإرسال حالياً محاكاة داخل المتصفح (`setTimeout`) ويُحفظ الطلب في `localStorage`.
لربطه بواجهة برمجية، استبدل كتلة المحاكاة في `js/main.js` داخل معالج `submit`:

```js
fetch('/api/orders', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(order)
})
  .then(function (r) { if (!r.ok) throw new Error('فشل الإرسال'); return r.json(); })
  .then(function (res) { /* أظهر رسالة النجاح ورقم الطلب res.id */ })
  .catch(function () { toast('تعذّر إرسال الطلب، حاول مجدداً'); });
```

> ملاحظة: التحقق في المتصفح لتجربة المستخدم فقط — تحقّق من البيانات على الخادم أيضاً.

## ملاحظات تقنية

- دعم كامل للاتجاه من اليمين لليسار (RTL) وأرقام عربية في كل العدادات.
- متجاوبة حتى عرض ٣٢٠ بكسل، بدون أي تمرير أفقي.
- تحترم `prefers-reduced-motion` فتُلغى الحركات لمن يفضّل ذلك.
- يُتحقق من رقم الجوال بصيغ `05XXXXXXXX` و `5XXXXXXXX` و `+9665XXXXXXXX`.
